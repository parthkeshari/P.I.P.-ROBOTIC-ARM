# Robot Voice Companion

A local voice-controlled companion that lets you talk to a robot naturally.
Speak to it, and it understands your intent, replies with speech, and performs physical gestures in real time.

---

## Overview

This project creates a simple and natural way to interact with a robot using voice.
You can speak or type, the system detects what you mean, replies out loud, and triggers matching robot gestures or joint movements.

The entire experience is designed to feel conversational and responsive.

---

## Features

- Voice input via microphone or typed text
- Speech-to-Text using Groq STT
- Natural replies generated by Groq LLM
- Text-to-Speech using Edge TTS
- Real-time robot gesture and joint control
- Simple terminal-based interface
- Wake-up and gesture support (e.g. WAKE → PEAK)

---

## Tech Stack

- **Speech-to-Text**: Groq STT
- **Text-to-Speech**: Edge TTS
- **Language Model**: Groq
- **Robot Control**: Cyberwave
- **Audio**: pygame + sounddevice
- **Language**: Python 3.10+

---

## Requirements

- Python 3.10 or higher
- Microphone and speakers
- Groq API key
- Cyberwave API key and Twin/Environment access

## Installation

1. Clone the repository:

```bash
git clone <your-repo-url>
cd <your-repo-name>
```

2. Create and activate a virtual environment:

```bash
python -m venv .venv
source .venv/bin/activate   # On Windows: .venv\Scripts\activate
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Set up your environment variables:

Copy the example file and fill in your own values:

```bash
cp .env.example .env
```

Then open `.env` and fill in your Groq API key and Cyberwave credentials.

---

## Usage

Run the companion:

```bash
python companion_local.py
```

### Controls

- Press Enter → Record from microphone
- Type text and press Enter → Skip microphone
- Type `quit` → Exit

### Example Interaction

```text
[Enter=mic | type text | quit]
Recording...
STT: "Hey, wake up"
intent: WAKE
reply: "Hi, I'm up..."
gesture: PEAK
```

## Environment Variables

All configuration is managed through a `.env` file. Use `.env.example` as a starting point:

| Variable | Description |
|---|---|
| `GROQ_API_KEY` | Your Groq API key for STT and LLM calls |
| `CYBERWAVE_API_KEY` | Your Cyberwave API key |
| `CYBERWAVE_TWIN_ID` | ID of the robot twin |
| `CYBERWAVE_ENVIRONMENT_ID` | ID of your Cyberwave environment |
| `CW_MODE` | Cyberwave mode (e.g. `playground`) |

Never commit your actual `.env` file, only `.env.example` should be tracked in git.

---

## Configuration

You can adjust the following inside the code or via environment variables:

- Recording duration
- Joint names (`_1` to `_6`)
- Voice settings for Edge TTS
- System prompt for the LLM
